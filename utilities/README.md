# Utilities

Supporting infrastructure — proxy, DNS, home automation, and a couple of
self-hosted tools I wanted to try.

- **dashboard/** — reverse proxy + service dashboard, socket-proxy pattern
- **pihole/** — network-wide DNS ad-blocking
- **homeassistant/** — automation, sensors, phone notifications
- **caldav/** — self-hosted calendar
- **uptime-kuma/** — tried, replaced by Home Assistant (see its README)
- **reactive-resume/** — self-hosted resume builder
