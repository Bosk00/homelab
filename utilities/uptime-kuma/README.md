# Uptime Kuma

Status/uptime monitoring for the other self-hosted services.

**Tried and removed:** ran this for a few days alongside Home Assistant.
Pulled the CPU usage CSV and compared the timeline before/after adding
Uptime Kuma — usage looked higher with it running. Not a rigorous
benchmark, but enough to convince me it wasn't worth the overhead. See
`utilities/homeassistant/` for what replaced it.
